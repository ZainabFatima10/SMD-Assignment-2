## About
**Kinnect** is a social media app UI built in Android Studio using **Java** and **XML**.
It contains 23 connected screens with working navigation and buttons (UI only).

## Screens
- 1–8: Splash, Login, Create account, Home feed, Reactions, Comments, Create post, Picture send
- 9–16: Camera, Story editor, Story viewer, Your story, Search, Friends, My profile, Edit profile
- 17–23: Other profile, Notifications, Menu, Chats, Chat, Call, Marketplace

## Layouts used
LinearLayout, RelativeLayout, ScrollView and DrawerLayout (Marketplace categories drawer).

## Structure
- `app/` – the Android Studio project (Gradle Kotlin DSL). Package: `com.zainabfatima.i221064`
- `Submission_Files/` – the XML resources and the Java/Kotlin source as submitted

## Run
Open the project in Android Studio, let Gradle sync, then run on an emulator or device.
